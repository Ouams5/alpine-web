GUIDE OF USE :

step 1 : download the project as a ZIP.
step 2 : Unzip using Winrar or any tool you like.
step 3 : download the x86 alpine Linux Virtual iso.
step 4 : add the iso to the folder where the project is and rename it to alpine-virt.iso.
step 5 : run the index.html and wait.

this runs locally on you machine. all of the stuff used like the libv86.js and the vgabios.bin etc.. are NOT owned by me nor i contributed to them, i just used them for this project.
